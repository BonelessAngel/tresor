        Geräte-Sync

        Gleicht deinen Tresor automatisch zwischen allen Geräten ab. Der Server sieht nur verschlüsselte Daten.

        Scanne den QR-Code mit der Kamera des anderen Geräts oder gib dort den Code ein (⚙️ → Geräte-Sync bzw. beim ersten Start „Mit Sync-Code verbinden“). Behandle den Code wie einen Schlüssel – zusammen mit dem Masterpasswort öffnet er deinen Tresor.
